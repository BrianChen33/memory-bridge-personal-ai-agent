# 网页与空间制作规范

让页面像 Linear 官网或苹果备忘录一样干净。目标简单、架构简单、设计简单、实现简单。

## 页面先服务一个主要任务

先确认用户打开页面要看什么、做什么。围绕这一件事安排标题、主体和主要操作，用布局、顺序、留白和对齐建立层次。

删去标语、装饰副标题、重复说明、教学式提示和缺乏决策价值的次要标签。一个页面需要额外文字解释用法时，先重排布局和操作入口。保留影响判断的真实状态、截止日期、来源、错误和必要表单标签。

首屏呈现概览。明细通过现有详情、折叠、筛选和分页按需展开。长名单按用户实际选择的对象分组，招聘场景以公司为一级、岗位为二级。

## 每个决定一起考虑 UX、DX 和 AX

| 维度 | 实施要求 |
|---|---|
| 用户体验 UX | 信息可扫读，操作可发现，手机和桌面都可用，正文有足够对比度，错误与缺失值真实可见。 |
| 开发者体验 DX | 复用现有数据、组件与生成器，结构清楚，样式集中，保留单一数据来源，减少重复渲染和不必要依赖。 |
| 智能体体验 AX | 使用语义标题、列表或表格，原生按钮、链接、输入与选择框，明确可访问名称，可读的选中、展开、禁用和结果状态。 |

原生控件支持键盘和焦点。图标按钮有可访问名称，状态同时提供文字。智能体与用户读取同一份页面状态。

## 更新已有页面

先找现有页面、真实源码或生成器和数据来源，记录关键功能、数据量、发布入口与访问范围。优先修改原页面及原生成入口，保持现有功能、数据、权限和稳定身份。删除视觉冗余时，确认相应功能仍有清晰可达的入口。

Muse 的资料库 HTML 通过真实文件和生成器更新。空间通过宿主正式创建、编辑、状态与交付工具更新。按真实类型操作，复用当前来源和身份。私有页面沿原私有入口交付，公开分享遵循宿主的用户授权要求。

## 系统面板

首页使用简洁标题、实际更新时间、带角色与可点击物件的小屋场景，以及八项状态卡片。角色小屋保留有用途的场景图与人格元素，周围的信息层级保持简洁。卡片只放关键当前值与必要补充数据。完整情绪、人物、日常、开关和阅读成长保留在对应详情中。词汇继续按学习状态分组，保留搜索和有界分页。更新、数据来源与素材许可集中在关于页面。

沿用现有快照数据、单文件 HTML 和情绪反馈任务末尾的静默生成。真实数值、未知项、失败状态和生成时间从当前记录读取。当前资料库入口和生成目标见部署环境的绑定记录。

## 验收与持续更新

完成后做一次聚焦验收，覆盖桌面、375px 手机、主要操作、键盘关闭与焦点恢复，并对照数据量、关键链接和更新入口。检查最新发布结果，再交付原页面。视觉规范接入制作和更新入口，避免下次生成恢复旧布局。

可复用面板和规范按 MAINTENANCE.md 发布到架构仓库。真实招聘资料、人物、私人记忆、登录态和部署标识按既有私有数据边界保存。
