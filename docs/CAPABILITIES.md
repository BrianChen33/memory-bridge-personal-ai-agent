# 能力边界（v0.4）

| 部分 | 仓库提供 | 仍需目标环境适配 |
|---|---|---|
| 六层状态核心 | 真实原话/记忆/模型情绪v2/持续期待/模拟精力联系欲望/生活事件 | 宿主模型正确提交评估、可信身份与scope |
| 随机生活 | 16类虚拟活动/梦境与真实文章注册 | 原生任务、模型理解、真实阅读工具与主动发送 |
| 检索 | 时间原话、关键词/向量/实体与排序、增量摘要、有界缓存 | 可选本地编码服务、后台摘要提炼 |
| 表情 | 通用一次抽签/候选随机/近期避重策略 | 素材许可、素材检索、平台媒体发送与客户端显示 |
| 提醒 | 账本/版本/原生runonce协作契约 | 平台实际调度精度和递送 |
| 面板 | 私有离线单文件HTML生成 | 宿主资料库发布；秒级在线API未包含 |
| GitHub认知快照 | 原格式导出、去重清单、代码commit、私库SSH发布回执 | 用户私库与正式授权、宿主SSH身份、真实总结链 |
| 继承 | 数据类别、模式、校验与隔离导入说明 | 用户选择/人格确认/当前工具和渠道重新授权 |

新root默认配置伙伴v2但总开关停用；旧root不自动切协议。蓝图不是已安装任务，模型支持v2不是prompt已经升级，命令成功不是消息送达。没有任何真实账号或记忆捆绑在公共包。

人物跨渠道自动猜认/合并、把外部群情绪写进主人私有scope、账号登录态继承、自动开通QQ/微信均不提供。仅有对话窗口而无持久工具权限的平台，不能靠读README完成运行时安装。
