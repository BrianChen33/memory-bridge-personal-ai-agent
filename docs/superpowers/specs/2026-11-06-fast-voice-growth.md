## Design

Learn specific words/phrases separately from abstract rhetorical mechanisms. A same-model, source-backed understanding judgment may admit a new term immediately to trial; only unclear meanings remain candidates with a reason. No three-post prerequisite for understood expressions. Up to8 lexical entries plus3 mechanisms per reading; owner teaching records the actual owner event, never fake article evidence. Known offensive gaming slang is not automatically excluded; preserve exact meaning, targets, intensity and scene constraints, use naturally under current persona/banter/emotion, do not blindly copy abusive targets or invent identities.

Context retrieves a few relevant entries, giving new trials room alongside mature expressions. No mandatory catchphrase per reply or second model. Correct contextual use, confirmed against real native assistant output, can build fluency (default3 uses across2 turns). Usage counts do not increase factual/source confidence. Silence is not positive feedback and positive owner praise is not mandatory.

Feedback distinguishes meaning correction, wrong context, excessive tone, and explicit stop. Only explicit stop/rejected legacy entries stay disabled against later reading; contextual corrections adjust applicability. Existing candidates are reviewed from actual archived quote evidence by the same model, not blindly bulk-promoted.

Stable, repeatedly appropriate habits may be reviewed for personality consolidation by the same model in the existing heartbeat, gated by existing personality_growth opt-in. It proposes a source-linked preference/temperament (not a regex word-to-personality rule), keeps immutable identity/appearance/permissions and supports reconsideration. It uses actual habits + observed uses + source evidence, not self-written invented experiences.
