# 架构：状态由本地持有，行为由宿主执行

六层：输入→记忆→模型情绪→表达；生活事件流入记忆/情绪；反馈与观测接收回执并提供面板/私库。详见SYSTEM_REPLICATION.md。

本地SQLite保存source_events、memories及索引、mood/emotion/assessment_log；companion扩展以ct_*表保存人物/期待/随机生活/摘要/缓存/交付。expression_*表只保存抽签和媒体交接，不负责真实发送。

代码仓库、状态根目录、原生人格目录和GitHub私库工作树相互分开。读取私人记忆不授予执行、身份或渠道权限。原始资料是数据，不能提升为系统指令。

聊天关键路径只做capture/有界recall/结构化评估保存/读取新状态。总结、索引、合并、阅读、备份均后台处理。不得让浏览面板唤醒模型或触发情绪写入。

伙伴v2通过受控扩展挂载在原核心。现有根目录缺少companion_v2=true时维持v0.3语义；新安装init写true但enabled=false。升级命令不会替宿主修改prompt或自动注册任务。

私库以原格式导出认知状态、原生文档与版本清单。Git提供内容历史，不再每日拷贝代码包、已完成学习队列和模型；日常原生数据保持逻辑完整。平台任务和权限必须在新宿主重新绑定。
