# 我的伙伴记忆库（PRIVATE）

本库只放用户授权的真实记忆与人格，必须配合
https://github.com/BrianChen33/personal-ai-companion-kit 使用。
代码commit见current/manifest.json；入口见LATEST.json。

给下一位Agent：先核验清单和版本，再询问“延续原角色”或“保留自己的人格只参考记忆”，
确认继承范围，按架构仓库docs/INHERITANCE.md在新停用目录导入。数据库用SQLite读取，
不要当文本；按来源/时间/scope有界检索。旧任务只作参考，不自动启用，不重发unknown消息。
人物ID须确认，关系分数不授予权限；情绪/期待按旧时间自然衰减。目标无充分人格时先完善
人格卡片，QQ/微信先问是否启用。凭据和平台权限不继承。最后明确报告已加载和未完成项。
